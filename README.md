# leather-shoe-shop
E-commerce website for leather shoe shop

## Tech Stack

**Frontend:**
- [Angular 21](https://angular.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [RxJS](https://rxjs.dev/)

**Backend:**
- [.NET 10](https://dotnet.microsoft.com/en-us/)
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
